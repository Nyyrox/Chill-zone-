# Chill Zone — AC Repair & Services (Muzaffarpur)

A lightweight, clean, and premium landing page for **Chill Zone AC Repair Services** in Muzaffarpur.

## 🚀 Features

- **Minimalist Monochrome Theme**: Light white and black design inspired by modern UI aesthetics.
- **Glassmorphic Navbar**: Smooth scroll-triggered blur and responsive mobile drawer.
- **Instant Cost Estimator**: Interactive dynamic calculator with multi-unit discounts.
- **Direct Booking Modal**: Doorstep service scheduling with toast notification feedback.
- **Verified Customer Reviews**: Horizontal scrolling testimonials carousel with controls.
- **FAQ Accordion**: Animated collapsible answers for service guarantees, response times, and testing.
- **Direct Contact & WhatsApp**: 1-click WhatsApp and phone call triggers.

## 🛠️ Tech Stack

- Semantic HTML5
- Vanilla CSS3 (Custom design system, CSS Variables, Responsive Grid/Flexbox)
- Vanilla JavaScript (Zero external libraries, ultra lightweight & blazing fast)

## 🌐 Live Preview

Open `index.html` in any modern web browser or deploy directly to GitHub Pages / Vercel.
