# Chill Zone AC Repair & Services — Landing Page

A React + Vite landing page for Chill Zone AC Repair & Services (Muzaffarpur),
built with an Urban-Company-inspired UX (hero + trust stats, service card grid,
step-by-step process, reviews, sticky call CTA) but its own visual identity.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

Output goes to `dist/` — upload that folder's contents to any static host
(Hostinger, Netlify, Vercel, etc.)

## Customize

- Phone number / email: search-replace `+918651726130` and `info@chillzonerepair.in`
  across `src/components/*.jsx`
- Services list: `src/components/Services.jsx`
- Reviews: `src/components/Reviews.jsx`
- Colors / fonts: CSS variables at the top of `src/index.css`
